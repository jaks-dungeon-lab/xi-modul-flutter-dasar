# Rangkuman Deployment

Selamat! Kamu telah menyelesaikan bab *Deployment* dan kini memahami bahwa kode mentah Fluttermu bisa diubah wujudnya ke berbagai bentuk untuk menjangkau semua penikmat pengguna.

## Intisari Materi

Berikut adalah poin-poin memori utama yang perlu kamu ingat dengan baik mengenai proses tahapan pembungkusan (*build*) pencetakan aplikasi:

- **Deployment**: Adalah istilah umum menamai proses memasak kode mentah pengembangan menjadi aplikasi bentuk jadi matang yang siap dikonsumsi disebarkan ke lapangan masyarakat umum.
- **APK**: Merupakan format wadah *file* pemasangan mutlak untuk masuk ke sistem operasi Android. Dihasilkan menggunakan perintah `flutter build apk` dan sangat mudah bisa dieksekusi dari komputer Windows apa pun.
- **IPA**: Merupakan wujud bungkusan kemasan aplikasi khusus untuk diserahkan ke ekosistem eksklusif Apple iPhone (iOS). Dihasilkan melalui mantara perintah `flutter build ipa`. Proses sakral ini mewajibkan si pembuat wajib murni untuk menggunakan duduk di depan komputer ber-OS Mac dan aplikasi pendamping mutlak bernama Xcode.
- **Web**: Merupakan kemampuan mengubah mentranslasi layar kode visual aplikasimu seketika menjadi bahasa bentuk struktur format internet murni (HTML/JS). Dihasilkan menggunakan alat perintah `flutter build web` di mana rentetan *file* dari *folder* akhirnya kelak dapat diletakkan diunggah (*hosting*) menjadi *link* alamat internet *website* aktif yang bisa diakses langsung ditekan dibuka lewat semua peramban dunia.
