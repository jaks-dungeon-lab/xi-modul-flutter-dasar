# Kelas XI Flutter Dasar

Modul pembelajaran Flutter Dasar untuk siswa kelas XI SMK. Modul ini disusun dengan pendekatan *Project-Based Learning* (PBL) untuk membimbing siswa dari konsep dasar hingga mampu membuat aplikasi sederhana menggunakan Flutter.

## Fitur Materi

- Pengenalan Flutter & Dart Dasar
- Penggunaan Layout & Widget (Container, Padding, Row, Column, dll)
- State Management Sederhana (StatefulWidget)
- Studi Kasus Pembuatan Aplikasi (Daftar Siswa & Kantin)
- Penjelasan Deployment ke Web/APK

## Deployment Otomatis (GitHub Pages)

Repositori ini telah dilengkapi dengan GitHub Actions untuk *deployment* otomatis menggunakan **MkDocs Material**. Setiap *push* ke *branch* `main` atau `master` akan secara otomatis memublikasikan pembaharuan situs dokumentasi ke GitHub Pages.

## Cara Menjalankan Lokal

1. Pastikan Python sudah terinstal di perangkatmu.
2. Install MkDocs Material dengan perintah: `pip install mkdocs-material`
3. Jalankan server lokal dengan perintah: `mkdocs serve`
4. Buka browser pada alamat `http://localhost:8000`
